Overview

Seal encode/decode helpers for prot payloads in pipelines. Built as a tiny zero-dependency Node toolkit with a library API and a stdin-friendly CLI.

Usage

git clone https://github.com/theworker02/sealprot.git
cd sealprot
node src/cli.js --help
node --test
